Install in three steps

  1. Download the zip

    Click Download Thief. Keep the file zipped. You don't need to open it.

  2. Add it to Deadlock Mod Manager

    Open Deadlock Mod Manager and click Add Local Mod in the sidebar. Drag the zip onto the drop box, type a name like "Thief", then click Add.

    No mod manager yet? It's free at deadlockmods.app.

  3. Enable it and play

    Go to Mods Library, find Thief and click Enable. Start the game with Launch modded.

Each look is its own mod, and only one Yamato skin can be on at a time. Enable one look and disable any other Yamato skin.

More help

Install without a mod manager
  1. Unzip the download. Inside is one file: pak01_dir.vpk.
  2. In Steam, right-click Deadlock and choose Manage, then Browse local files.
  3. Open game\citadel. If there's no addons folder, create one.
  4. Move pak01_dir.vpk into addons. If a file with that name is already there, rename yours to the next free number instead: pak02_dir.vpk, pak03_dir.vpk and so on.
  5. One-time setup: open game\citadel\gameinfo.gi in Notepad, find SearchPaths, and add the highlighted line right under Game_Language. Save the file. 
    SearchPaths
{
    Game_Language   citadel_*LANGUAGE*
    Game            citadel/addons
    Mod             citadel
    ...

Deadlock updates can reset gameinfo.gi. If mods stop loading after a patch, add the line again. Deadlock Mod Manager does this for you automatically.

Update to a new version
  1. Download the new zip from this page.
  2. In Deadlock Mod Manager, open Mods Library, open Thief and click Delete Mod to remove the old version.
  3. Add the new zip with Add Local Mod and enable it, the same as the first install.

Installed by hand? Replace your pakNN_dir.vpk in addons with the one from the new zip, keeping the same file name.

Mods added with Add Local Mod don't get update alerts in the mod manager, so check this page now and then.

Uninstall

In Deadlock Mod Manager, click Disable to turn it off, or Delete Mod to remove it completely. Installed by hand? Delete the pakNN_dir.vpk you added to addons.

The skin doesn't show up in game
  • Make sure Thief is enabled in Mods Library and that no other Yamato skin is enabled.
  • Close Deadlock completely and start it again with Launch modded. Mods load when the game starts.
  • Still nothing? In Deadlock Mod Manager, disable all mods, delete Thief, add the zip again and enable only this mod.
I installed it from GameBanana before

Please replace it with the version on this page. The first version could make other players' Yamatos T-pose or crash the game in matches. Delete the old one in Deadlock Mod Manager, then follow the three steps above.

Can other players see it?

No. Mods only change your own game. You'll see every Yamato as Thief, and other players see whatever they have installed. It changes looks and sounds only, nothing about gameplay.
